Seth Anandram Jaipuria School's Library Website

This document provides an overview of the Seth Anandram Jaipuria School Library Website, developed by Manav Kumar Mishra of Class VIII-D

The website is designed to provide students, teachers, and library administrators with a centralized digital platform for accessing the school library’s catalogue, schedules, discussions, book information, user profiles, and other library-related resources.

The website is designed using publicly available technologies and services. The core website can be created, hosted, and managed at little to no cost within the applicable free usage limits of the services used.

Purpose of the Website

The main purpose of the website is to digitize and simplify the management and use of the school library.

Instead of keeping information about books, schedules, discussions, and users in separate places, the website brings these features together into a single platform.

The website aims to:

  • Make the library catalogue easily accessible to students.
  • Provide detailed information about books.
  • Allow students to discuss books and exchange perspectives.
  • Make library schedules easier to access.
  • Provide students with customizable profiles.
  • Allow users to discover and learn about other registered members.
  • Give teachers and administrators tools to manage the library.
  • Provide a centralized system for moderation and record keeping.
  • Create a foundation that can be expanded with additional features in future versions.

Languages and Services Used

HTML, CSS and JavaScript

The frontend of the website is built using three core web technologies:

  • HTML (HyperText Markup Language): Provides the structure and content of the website.
  • CSS (Cascading Style Sheets): Controls the appearance, layout, responsiveness, and visual design of the website.
  • JS (JavaScript): Adds interactivity, dynamic content, data handling, and other interactive functionality.

Together, these development languages allow the website to remain responsive, organized, and easy to use across different devices.

Firebase

Firebase, a Google platform, is used for several backend services of the website. Depending on the feature, Firebase is responsible for services such as:

  • User authentication and login.
  • Storage and retrieval of book information.
  • User profile data.
  • Discussions, comments, and messages.
  • Reviews and other library-related information.
  • Database operations.
  • Access control and management of user permissions.

Firebase allows the website to use a cloud-based backend without requiring the project to maintain its own physical server. The services used by the project can be operated within Firebase's applicable free usage limits, making the website practical to develop and maintain without requiring a large infrastructure budget.

GitHub

GitHub, a Microsoft-owned developer platform, is used for source-code management, version control, and website hosting. It is responsible for:

  • Storing and organizing the website's source code and project files.
  • Keeping track of changes made to the project through version control.
  • Providing a reliable backup of the project's files.
  • Hosting the website using GitHub Pages, making it possible to manage and update the website without requiring a separate hosting server.

Website Structure

The website contains six main pages available to general users, along with an additional Manage page that is accessible only to authorized teachers and administrators. The pages and their functions are described below.

1. Home

The Home page acts as the main introduction to the library website. It provides users with quick access to important sections of the website and highlights useful information such as:

  • Introduction to the digital library.
  • Shortcuts to important sections.
  • Featured books.
  • Recently added books.
  • Other important library updates.

The purpose of the Home page is to give users a quick overview of the library and allow them to reach the information they need without unnecessary navigation.

2. Library

The Library page contains the digital catalogue of books available on the website. Authorized teachers and administrators can add detailed information about books, including:

  • Title, Author, and Publication year.
  • Genre, Themes, Characters, and Setting.
  • Plot, Conflicts, Resolutions, Moral or lessons, and Summary.

This information is then presented to students and other authorized users in an organized format. The Library page therefore acts as the central source of information about the books available in the school's digital catalogue.

3. Discussions

The Discussions section allows users to communicate and exchange ideas about books they are reading. Students can use discussions to share opinions, discuss characters and events, ask questions, exchange interpretations, discuss themes, and gain perspectives from other readers.

A major feature of this section is automatic discussion creation. Whenever a new book is added to the library, a discussion associated with that book can be created automatically. The discussion system also includes word filtering to help prevent inappropriate or abusive language from being used on the platform. This makes the library more interactive rather than functioning only as a catalogue of books.

4. Schedule

The Schedule page provides students with information about their weekly library periods. Authorized teachers and administrators can add schedule information including Date, Day, Period, Grade, Section, Teacher, Genre or shelf to read, and Additional notes.

The day can be automatically determined from the selected date, reducing the amount of information that staff members need to enter manually. The schedule allows students to quickly check what is planned for their library period.

Planned Improvements: A future version of the website may include a Schedule History feature. This would allow users to view previous library schedules instead of only the current or upcoming schedule.

5. Discover People

The Discover People section provides an alphabetical directory of registered users. It allows students to learn more about the people they interact with on the platform while keeping the amount of publicly visible information limited.

Depending on the user's profile settings and the website's access rules, information displayed may include Name, Class, Section, Roll number, Bio, and Last online status. Sensitive information such as passwords and authentication credentials is not displayed to other users. The purpose of this feature is to make the platform more social and help users identify the people participating in library discussions.

6. Dashboard

The Dashboard is the personal profile and account management area of the website. Users can manage information about their profile and customize the information they choose to share. Users can edit their profile information while their unique user ID remains system-assigned and cannot be manually changed. This ensures that the identifier associated with an account remains consistent even when the user's profile information is updated.

7. Manage

The Manage page is a restricted management dashboard available only to authorized teachers and administrators. It provides centralized tools for managing the website and its content. The management dashboard includes areas such as:

  • Catalogue Management: Allows authorized staff to add, edit, and manage books in the digital catalogue.
  • Review Moderation: Provides tools for reviewing and moderating book-related reviews or user-submitted content.
  • User Management: Allows authorized staff to manage registered users and take appropriate moderation or administrative actions.

By bringing these functions together, the Manage page provides staff with a centralized and organized method of administering the digital library.

Security and Access Control

Since the website handles user accounts and library-related data, access control is an important part of the system. Different users can have different levels of access depending on their role. For example:

  • Students can access normal library features.
  • Teachers can access additional management functions where authorized.
  • Administrators can access the full management dashboard and administrative functions.

Restricted features are not intended to be available to ordinary users. Authentication and database services are handled through Firebase, while access rules can be used to control which users are allowed to read or modify different types of information. The website also avoids displaying sensitive account information such as passwords to other users.

Key Features

The major features of the website can be summarized as follows:

  • Digital library catalogue.
  • Detailed book information.
  • Book discussions and reviews.
  • Automatic discussion creation for newly added books.
  • Weekly library schedules.
  • User profiles.
  • User discovery system.
  • Role-based management.
  • Book and review management.
  • User management.
  • Audit logging.
  • Content moderation.
  • Responsive web design.
  • Cloud-based backend and database.

These features make the website more than a simple digital book catalogue; it functions as a complete digital library management and interaction platform.

Future Improvements

The website is designed so that additional features can be introduced in future versions. Some planned or possible improvements include:

  • Schedule History: Allow users to view previous library schedules.
  • Reading Lists: Allow students to create personal lists of books they want to read.
  • Book Recommendations: Recommend books based on a user's interests or reading history.
  • Notifications: Notify users about new books, schedule changes, or discussion activity.
  • Improved Moderation: Expand automated filtering and moderation tools.
  • Analytics: Provide administrators with useful statistics about catalogue usage and student interaction.
  • Book Availability Tracking: Track whether physical copies of books are available, issued, or reserved.
  • Mobile Improvements: Continue improving the responsive experience for phones and tablets.
  • Additional Administrative Tools: Introduce more tools for managing library operations digitally.

These improvements could gradually turn the website into a more comprehensive digital library management system.

Conclusion

The Seth Anandram Jaipuria School Library Website is designed to bring the school's library resources, information, communication, and management tools together into one centralized platform.

By combining a modern web interface with cloud-based services such as Firebase, the project provides students with easier access to books, schedules, discussions, and user profiles while giving teachers and administrators dedicated tools for managing the platform.

The project also provides a strong foundation for future development. Features such as schedule history, advanced searching, reading lists, recommendations, notifications, analytics, and physical book availability can be added as the system grows.

Overall, the goal of the project is not simply to create a website for the library, but to create a digital ecosystem that makes reading, discovering, discussing, and managing library resources easier and more organized for the entire school community.
